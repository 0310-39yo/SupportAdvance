## 0. 本書の位置づけ

MockClock は、IClock インターフェースの汎用テスト用実装。指定した固定の時刻を返し、Set() メソッドで動的に時刻を変更できます。

**設計上の特徴:**
- **型**: sealed class、IClock インターフェース実装
- **目的**: テスト時に任意の時刻を指定・変更
- **責務**: 設定時刻を返す、Set() で時刻を変更可能
- **使用シーン**: 特定の時刻条件下での動作検証、テスト途中での時刻変更
- **実装済みテスト**: MockClockTests.cs

本仕様書は、MockClock の時刻取得・変更・インターフェース適合性を確認するテスト仕様。

---

## 1. テスト目的

MockClock が以下を満たすことを確認する：

- **初期化**: 初期時刻を受け取れる
- **時刻取得**: JstNow で設定時刻を返す
- **時刻変更**: Set() で動的に時刻を変更できる
- **固定性**: 複数呼び出しで時刻は同じ（変更されるまで）
- **インターフェース**: IClock の契約を満たす

## 5. テスト仕様別の検証シナリオ

### 観点 IN-01: 初期時刻の確認

#### 5.1.1 テスト観点

MockClock(initialTime) の JstNow が initialTime に等しい。

#### 5.1.2 テストパターン

| パターン | 説明 |
|---------|------|
| 5.1.2.1 | MockClock(2026-01-01 12:00:00) → JstNow = 2026-01-01 12:00:00 |

#### 5.1.3 期待結果

- [ ] JstNow == initialTime

---

### 観点 SE-01: Set メソッドによる時刻変更

#### 5.2.1 テスト観点

Set() で時刻を変更すると、その新しい時刻が JstNow で返される。

#### 5.2.2 テストパターン

| パターン | 説明 |
|---------|------|
| 5.2.2.1 | MockClock(2026-01-01) → Set(2026-02-01) → JstNow = 2026-02-01 |

#### 5.2.3 期待結果

| ステップ | 期待値 |
|--------|--------|
| 初期化後 | JstNow = 2026-01-01 |
| Set(2026-02-01) 実行後 | JstNow = 2026-02-01 |

#### 5.2.4 判定基準

- [ ] Set() 後に JstNow が新しい値を返す

---

### 観点 SE-02: 複数回の Set() 操作

#### 5.3.1 テスト観点

複数回 Set() を呼び出した場合、最後に設定した値が返される。

#### 5.3.2 テストパターン

| パターン | 説明 |
|---------|------|
| 5.3.2.1 | Set(A) → Set(B) → Set(C) |

#### 5.3.3 期待結果

- [ ] 最終的に JstNow == C

## 6. 前提条件・制限事項

- **テスト環境**: xUnit 2.0+ with Assert

- **依存モック**: なし（LocalDateTime は値型、計算のみ）

- **スレッド安全性**: 単一スレッドでのテストを想定（マルチスレッドでの Set() 呼び出しは考慮対象外）
- **スキップテスト**: なし（全テストが実施可能）
