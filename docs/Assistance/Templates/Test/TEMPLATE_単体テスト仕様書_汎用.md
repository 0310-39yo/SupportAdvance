## 0. 本書の位置づけ

本書は、Advance プロジェクトの **一般的なクラス（Utility、Helper、Converter、Validator、Calculator等）** が、
技術仕様書および詳細設計書で定義された **機能・アルゴリズム・出力形式** を満たすことを確認するテスト仕様書。

ValueObject / Entity / DomainService / UseCase 以外の、その他すべてのクラスに対応。

---

## 1. テスト目的

[対象クラス] の各メンバーが、以下の仕様を満たすことを確認する：

- **正常系処理**：正しい入力に対して期待される出力が得られる
- **入力検証**：不正な入力を正しく検出し、例外で拒否する
- **境界値処理**：最小値・最大値・空文字列等の境界値で正しく動作
- **エラーハンドリング**：予期しない状況でも安全に処理される
- **パフォーマンス**：計算量・実行時間が仕様を満たす

## 5. 判定基準

### 5.1 全般的な判定基準

| 項目 | 基準 |
|------|------|
| **正常系** | 標準的な入力で期待される出力が得られることが明確であること |
| **入力検証** | 不正な入力が正しく検出されること |
| **境界値** | 境界値での処理が仕様を満たすこと |
| **エラー処理** | 予期しない状況でも安全に処理されること |
| **パフォーマンス** | 処理時間・メモリが仕様を満たすこと |
