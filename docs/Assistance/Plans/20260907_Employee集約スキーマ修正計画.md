# Employee 集約スキーマ修正計画

**作成日:** 2026-09-07  
**対象:** Employee Context  
**目的:** DDD 原則に準拠したスキーマ設計への移行

---

## 📋 概要

現在の Employee Context は、DDD の複数Entity集約（パターン1）の原則に基づいて設計されていますが、**データベーススキーマが実装と乖離** しています。本計画では、以下を実施して完全な一貫性を実現します：

1. **m_employee_attributes テーブルの廃止**
2. **m_persons への employee_row_id FK追加**
3. **Mapper/Repository の修正**
4. **Context間データ共有パターンの適用**

---

## 🔍 現状分析

### Domain層の設計（正しい）

```csharp
public class Employee : AggregateRoot<EmployeeRowId>
{
    public Person Person { get; private set; }  // ← 1:1 内包
    public IReadOnlyCollection<DepartmentMembership> DepartmentMemberships { get; }  // ← 1:N 内包
}
```

**分類：**
- Person: Employee と 1:1 関係（必須、常に一体）
- DepartmentMembership: Employee と 1:N 関係（複数可、独立した配属）

### 現在のDB層（問題あり）

```sql
m_employees
  [row_id] PK
  ※ person_row_id なし

m_persons
  [row_id] PK
  ※ employee_row_id なし（逆参照なし）

m_employee_attributes
  [row_id] PK
  [employee_row_id] FK
  [attribute_type]  -- ジェネリック参照テーブル（複雑性高）
  [attribute_row_id]

m_department_memberships
  [row_id] PK
  [employee_row_id] FK  -- ← 正しい 1:N 設計
  [department_row_id]
```

**問題:**
1. m_persons が employee_row_id を持たない（1:1 関係が不明確）
2. m_employee_attributes が Person/DepartmentMembership の両方をマッピング（混在）
3. ジェネリック参照テーブルの複雑性（型安全性喪失）
4. Domain層と DB層のギャップ

## ✅ 目標設計（修正後）

### DB スキーマ（パターン1準拠）

```sql
【1:1 属性（Person）】
m_employees
  [row_id] PK
  [biz_division]
  [biz_id]
  [retired_on]
  -- 他のカラムは削除

m_persons
  [row_id] PK
  [employee_row_id] FK → m_employees  ← 【追加】1:1 関係を明示
  [last_name]
  [first_name]
  [last_name_kana]
  [first_name_kana]
  [created_at] / [created_by] / [updated_at] / [updated_by] / [deleted_at] / [deleted_by]
  [row_version]

【1:N 属性（DepartmentMembership）】
m_department_memberships
  [row_id] PK
  [employee_row_id] FK → m_employees  ← 既に正しい（複数行が同じ値）
  [department_row_id]
  [is_primary]
  [end_on]
  [監査カラム 8個]
  [row_version]
```

### 削除対象

- **m_employee_attributes テーブル全体** ← 廃止
  - ジェネリック参照テーブルの複雑性排除
  - 1:1 と 1:N が混在する設計の解消

### Domain層の実装（変更なし）

```csharp
// 既存実装はそのまま有効
public class Employee : AggregateRoot<EmployeeRowId>
{
    public Person Person { get; private set; }
    public IReadOnlyCollection<DepartmentMembership> DepartmentMemberships { get; }
}
```

### フェーズ2：Mapper 層の修正

**対象ファイル:**
- `src/Contexts/Employee/Employee.Infrastructure/Mappers/EmployeeMapper.cs`

**修正内容:**

```csharp
// 既存のジェネリック参照テーブル経由のマッピングを削除
// ↓ 以下のようなシンプルなマッピングに統一

public class EmployeeMapper
{
    /// <summary>
    /// DbModel → Domain Entity への変換
    /// </summary>
    public static Employee ToEmployee(
        EmployeeDbModel employeeDbModel,
        PersonDbModel personDbModel,
        IEnumerable<DepartmentMembershipDbModel> membershipDbModels,
        IClock clock)
    {
        ArgumentNullException.ThrowIfNull(employeeDbModel);
        ArgumentNullException.ThrowIfNull(personDbModel);
        ArgumentNullException.ThrowIfNull(membershipDbModels);

        // 子Entity の復元
        var person = PersonMapper.ToEntity(personDbModel);
        var memberships = membershipDbModels
            .Select(m => DepartmentMembershipMapper.ToEntity(m))
            .ToList();

        // 集約の復元
        return Employee.Reconstruct(
            rowId: EmployeeRowId.From(employeeDbModel.RowId),
            typeDivision: BizDivision.From(employeeDbModel.BizDivision),
            bizId: BizId.From(employeeDbModel.BizId),
            bizCode: BizCode.From(employeeDbModel.BizCode),
            retiredOn: RetiredOn.TryFromDbValue(employeeDbModel.RetiredOn, out var ro) ? ro : RetiredOn.Unset(),
            person: person,
            departmentMemberships: memberships
        );
    }

    /// <summary>
    /// Entity → DbModel への変換
    /// </summary>
    public static EmployeeDbModel ToEmployeeDbModel(Employee employee)
    {
        return new EmployeeDbModel
        {
            RowId = employee.RowId.Value,
            BizDivision = employee.TypeDivision.ToString(),
            BizId = (int)employee.BizId.Value,
            BizCode = employee.BizCode.Value,
            RetiredOn = employee.RetiredOn.HasRetired ? employee.RetiredOn.Value.Value : (DateTime?)null
        };
    }
}

// PersonMapper は employee_row_id をマッピング対象に追加
public class PersonMapper
{
    public static PersonDbModel ToPersonDbModel(Person person, long employeeRowId)
    {
        return new PersonDbModel
        {
            RowId = person.RowId.Value,
            EmployeeRowId = employeeRowId,  // ← 【追加】1:1 リンク
            LastName = person.LastName.Value,
            FirstName = person.FirstName.Value,
            LastNameKana = person.LastNameKana.Value,
            FirstNameKana = person.FirstNameKana.Value
        };
    }
}
```

### フェーズ3：Repository 層の修正

**対象ファイル:**
- `src/Contexts/Employee/Employee.Infrastructure/Repositories/EmployeeRepository.cs`

**修正内容:**

```csharp
public class EmployeeRepository : IEmployeeRepository
{
    private readonly IDbConnection _connection;
    private readonly IClock _clock;

    /// <summary>
    /// Employee を読み込み（複数テーブル JOIN）
    /// </summary>
    public async Task<Employee?> GetByIdAsync(EmployeeRowId employeeRowId)
    {
        using var connection = GetConnection();

        // 1. m_employees テーブルを読み込み
        var employeeDbModel = await connection.QuerySingleOrDefaultAsync<EmployeeDbModel>(
            @"SELECT [row_id], [row_version], [biz_division], [biz_id], [biz_code], [retired_on]
              FROM [dbo].[m_employees]
              WHERE [row_id] = @RowId",
            new { RowId = employeeRowId.Value }
        );

        if (employeeDbModel == null)
            return null;

        // 2. m_persons テーブルを読み込み（employee_row_id で結合）
        var personDbModel = await connection.QuerySingleOrDefaultAsync<PersonDbModel>(
            @"SELECT [row_id], [row_version], [employee_row_id], [last_name], [first_name], [last_name_kana], [first_name_kana]
              FROM [dbo].[m_persons]
              WHERE [employee_row_id] = @EmployeeRowId",
            new { EmployeeRowId = employeeRowId.Value }
        );

        if (personDbModel == null)
            throw new InvalidOperationException($"Person not found for Employee {employeeRowId}");

        // 3. m_department_memberships テーブルを読み込み（複数行）
        var membershipDbModels = await connection.QueryAsync<DepartmentMembershipDbModel>(
            @"SELECT [row_id], [row_version], [employee_row_id], [department_row_id], [is_primary], [end_on]
              FROM [dbo].[m_department_memberships]
              WHERE [employee_row_id] = @EmployeeRowId
              AND [deleted_at] IS NULL",
            new { EmployeeRowId = employeeRowId.Value }
        );

        // 4. Mapper で Entity に変換
        return EmployeeMapper.ToEmployee(
            employeeDbModel,
            personDbModel,
            membershipDbModels,
            _clock
        );
    }

    /// <summary>
    /// Employee を保存（複数テーブル トランザクション）
    /// </summary>
    public async Task SaveAsync(Employee employee)
    {
        using var connection = GetConnection();
        using var transaction = connection.BeginTransaction(IsolationLevel.ReadCommitted);

        try
        {
            var updatedAt = _clock.JstNow;

            // 1. m_employees を UPDATE
            var empRowsAffected = await connection.ExecuteAsync(
                @"UPDATE [dbo].[m_employees]
                  SET [biz_division] = @BizDivision,
                      [biz_id] = @BizId,
                      [biz_code] = @BizCode,
                      [retired_on] = @RetiredOn,
                      [updated_at] = @UpdatedAt,
                      [updated_by] = @UpdatedBy,
                      [row_version] = DEFAULT
                  WHERE [row_id] = @RowId
                  AND [row_version] = @OldRowVersion",
                new
                {
                    RowId = employee.RowId.Value,
                    BizDivision = employee.TypeDivision.ToString(),
                    BizId = (int)employee.BizId.Value,
                    BizCode = employee.BizCode.Value,
                    RetiredOn = employee.RetiredOn.HasRetired ? employee.RetiredOn.Value.Value : (DateTime?)null,
                    UpdatedAt = updatedAt.Value,
                    UpdatedBy = GetCurrentUserId(),
                    OldRowVersion = employee.RowVersion
                },
                transaction: transaction
            );

            if (empRowsAffected == 0)
                throw new ConcurrencyException("Employee was updated by another user");

            // 2. m_persons を UPDATE（employee_row_id は変わらない）
            var personDbModel = EmployeeMapper.ToPersonDbModel(employee.Person, employee.RowId.Value);
            var perRowsAffected = await connection.ExecuteAsync(
                @"UPDATE [dbo].[m_persons]
                  SET [last_name] = @LastName,
                      [first_name] = @FirstName,
                      [last_name_kana] = @LastNameKana,
                      [first_name_kana] = @FirstNameKana,
                      [updated_at] = @UpdatedAt,
                      [updated_by] = @UpdatedBy,
                      [row_version] = DEFAULT
                  WHERE [row_id] = @RowId
                  AND [row_version] = @OldRowVersion",
                new
                {
                    RowId = personDbModel.RowId,
                    LastName = employee.Person.LastName.Value,
                    FirstName = employee.Person.FirstName.Value,
                    LastNameKana = employee.Person.LastNameKana.Value,
                    FirstNameKana = employee.Person.FirstNameKana.Value,
                    UpdatedAt = updatedAt.Value,
                    UpdatedBy = GetCurrentUserId(),
                    OldRowVersion = employee.Person.RowVersion
                },
                transaction: transaction
            );

            if (perRowsAffected == 0)
                throw new ConcurrencyException("Person was updated by another user");

            // 3. m_department_memberships を更新（追加・削除・更新）
            // ← 既存ロジック継続

            transaction.Commit();
        }
        catch
        {
            transaction.Rollback();
            throw;
        }
    }
}
```

```csharp
// src/Application/Queries/IQueryService.cs（既存）
public interface IQueryService<TAggregate, TId> 
    where TAggregate : IAggregateRoot
{
    Task<TAggregate?> GetByIdAsync(TId id);
}

// src/Contexts/Employee/Employee.Application/Queries/EmployeeQueryService.cs
public class EmployeeQueryService : IQueryService<Employee, EmployeeRowId>
{
    private readonly IEmployeeRepository _repository;

    public async Task<Employee?> GetByIdAsync(EmployeeRowId id)
    {
        return await _repository.GetByIdAsync(id);
    }
}

// Program.cs で DI 登録
services.AddScoped<IQueryService<Employee, EmployeeRowId>, EmployeeQueryService>();
```

**利用例（他Context から）:**

```csharp

        if (employee == null)

    }
}
```
