## エラー分類と根本原因

### 1. **RowId コンストラクタ署名エラー** (CS1729)

**affected files:**
- `PersonRowIdTests.cs` (5 errors)
- `DepartmentMembershipRowIdTests.cs` (6 errors)
- `DepartmentRowIdTests.cs` (6 errors)
- `EmployeeRowIdTests.cs` (未確認、同パターン予想)

**エラー例:**
```
error CS1729: 'PersonRowId' には、引数 1 を指定するコンストラクターは含まれていません
```

**原因:**
テストは `new PersonRowId(123L)` の形で構築を試みているが、実装では `PersonRowId.From(123L)` が正しい API。

**確認項目:**
- [ ] `PersonRowId.cs` のコンストラクタは private か？
- [ ] `From()` static メソッドが存在するか？
- `EmployeeRowId`, `DepartmentRowId` 等も同じパターン

### 2. **ValueObject 未実装 or API ズレ** (CS0117)

**Affected classes (TryFrom メソッド欠落):**
- `LastName.TryFrom()` (2 errors)
- `FirstName.TryFrom()` (2 errors)
- `LastNameKana.TryFrom()` (2 errors)
- `FirstNameKana.TryFrom()` (1 error)
- `EndOn.TryFrom()` (2 errors)

**Affected properties (プロパティ欠落):**
- `EndOn.Date` property (2 errors) — テストが `.Date` プロパティを参照

**原因:**
- 実装済みの `BizId`, `BizCode` 等は `From()` / `TryFrom()` メソッドを持つ
- 新規 ValueObject (`FirstName` 等) はまだ実装されていない

**確認項目:**
- [ ] Person Name ValueObjects (FirstName, LastName, FirstNameKana, LastNameKana) は実装済みか？
- [ ] EndOn ValueObject に `.Date` プロパティはあるか？

### 3. **クラス定義の欠落** (CS0103, CS0246)

**Affected class names (namespace レベルで定義):**
- `EmploymentStatus` — 8+ エラー（クラス定義が無い）
- `EmployeeNumber` — 9 エラー（これは先ほど修正 ✓）

**Affected class names (using ディレクティブ欠落):**
- `LocalDateTime` — `EmployeeRetiredEventTests.cs` に 6 エラー
- `IDomainEvent` — `EmployeeRetiredEventTests.cs` に 1 エラー

**原因:**
- `EmploymentStatus` は Employee.Domain に未実装？
- `EmployeeRetiredEventTests.cs` が `using SupportAdvance.Common.Clocks` / `using SupportAdvance.SharedKernel` を忘れている

**確認項目:**
- [ ] `Employee/ValueObjects/Employee/EmploymentStatus.cs` は実装済みか？
- [ ] `EmployeeRetiredEventTests.cs` の using ディレクティブを確認

### 4. **Entity 構築エラー** (CS1729)

**Affected in:**
- `PersonTests.cs` — PersonRowId, LastName, FirstName, LastNameKana, FirstNameKana のコンストラクタエラー (5 errors × 2 test methods)
- `DepartmentMembershipTests.cs` — DepartmentMembershipRowId, EmployeeRowId, DepartmentRowId, IsPrimary のコンストラクタエラー (4 per method × 2)

**原因:**
Person, DepartmentMembership Entity がまだ実装されていないか、コンストラクタ API がテストと異なる。

### 5. **async/await 不正使用** (CS0619)

**Affected in:**
- `EmployeeRetiredEventTests.cs` — 2 errors

**エラー例:**
```csharp
Assert.Throws<T>(Func<Task>)  // ❌ 旧形式
Assert.ThrowsAsync<T>(...)     // ✓ 正しい形
```

**原因:**
async テストで `await` を伴わない `Assert.Throws()` 呼び出し。xUnit 2.0+ では `Assert.ThrowsAsync()` を使用すること。

### 6. **未定義メンバアクセス** (CS0103)

**Affected in:**
- `DepartmentMembershipTests.cs` (line 88) — `departmentRowId` 変数が未定義
- `DepartmentMembershipTests.cs` (line 142) — `endOn` 変数が未定義

**原因:**
テストコード内の変数名が誤っている、または変数が定義されていない。
