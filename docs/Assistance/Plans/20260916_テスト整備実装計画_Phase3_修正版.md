### 3-0-1: PersonRowId_単体テスト仕様書.md

**ファイル位置:** `docs/Contexts/Employee/Domain/ValueObjects/Person/PersonRowId_単体テスト仕様書.md`

**テスト対象:** `tests/Contexts/Employee.Domain.Tests/ValueObjects/Person/PersonRowIdTests.cs`

**内容:**

テンプレート `TEMPLATE_単体テスト仕様書_ValueObject.md` を使用し、以下の章立てで作成：

1. **0. 本書の位置づけ**
   - PersonRowId は Employee 集約の個人基本情報（Person Entity）の DB 行 ID
   - RowId の specialized 型（SharedKernel.RowId 基底）
   - テストは `PersonRowId.From()` factory method の検証

2. **1. テスト目的**
   - 有効な ID 値で構築できることを検証
   - 等価性（Equal）が正しく判定されることを検証
   - FromDbValue での NULL 処理検証（オプション）

3. **2. テスト対象クラス**
   - `SupportAdvance.Contexts.Employee.Domain.ValueObjects.Person.PersonRowId`

4. **3. テスト対象メソッド**
   - `From(long value)` — static factory
   - `TryFrom(long value, out PersonRowId result)` — try パターン
   - `Equals(object? obj)` — 等価性判定

5. **4. テスト観点**
   - **RowId-FROM**: From() で有効値から構築成功
   - **RowId-EQ**: 同じ値で構築された 2 つのインスタンスが等価
   - **RowId-NE**: 異なる値で構築されたインスタンスが非等価
   - **RowId-TRY**: TryFrom で try パターンで安全に構築

6. **5. テスト仕様**
   - 実装済みテスト `PersonRowIdTests.cs` から観点を抽出
   - 各テストメソッドを観点にマッピング

7. **6. 前提条件・制限事項**
   - RowId はデータベース行 ID のみを保持
   - 負数は許容（DB では通常正数だが、型上は long）

8. **7. 改版履歴**
   - 初版 2026-09-16（Phase 2 ドキュメント補完）
