# ドメインイベント 設計ガイド

Domain Driven Design におけるドメインイベントの設計と実装パターンです。

---

## 📋 基本原則

### ドメインイベントの役割

ドメインイベントは Entity が発行する「重要な業務上の変更」を表します。

- **疎結合**: イベント発行者と購読者が直接依存しない
- **非同期対応**: イベント購読者は非同期で処理可能
- **監査**: 何が起きたかを記録し、追跡可能にする
- **統合**: Bounded Context 間の連携メカニズム

### イベント識別子

ドメインイベントは **AggregateRootId（rowId）** で識別します。

```csharp
public interface IDomainEvent
{
    long AggregateRootId { get; }      // イベント発行元の AggregateRoot の rowId
    DateTime OccurredOn { get; }        // イベント発生時刻
}
```

## 💡 実装パターン

### 1. イベント定義

```csharp
// src/Contexts/YourGroup/YourContext/YourContext.Domain/DomainEvents/YourEntityCreatedEvent.cs

using SupportAdvance.SharedKernel.DomainEvents;

namespace SupportAdvance.Contexts.YourGroup.YourContext.Domain.DomainEvents;

/// <summary>
/// YourEntity が作成されたことを表すドメインイベント
/// 【識別子】AggregateRootId（rowId）で識別
/// 【発生タイミング】Entity コンストラクタで自動発行
/// 【用途】監査、他BC への通知、サイドエフェクト実行
/// </summary>
public class YourEntityCreatedEvent : IDomainEvent
{
    public long AggregateRootId { get; }
    public DateTime OccurredOn { get; }

    public YourEntityCreatedEvent(long aggregateRootId)
    {
        if (aggregateRootId <= 0)
            throw new ArgumentException("AggregateRootId は正の値である必要があります。");

        AggregateRootId = aggregateRootId;
        OccurredOn = DateTime.UtcNow;
    }
}
```

### 2. 複数の属性を持つイベント

```csharp
// src/Contexts/YourGroup/YourContext/YourContext.Domain/DomainEvents/YourEntityUpdatedEvent.cs

using SupportAdvance.SharedKernel.DomainEvents;

namespace SupportAdvance.Contexts.YourGroup.YourContext.Domain.DomainEvents;

public class YourEntityUpdatedEvent : IDomainEvent
{
    public long AggregateRootId { get; }
    public DateTime OccurredOn { get; }
    
    // イベント固有の属性
    public string FieldName { get; }
    public string OldValue { get; }
    public string NewValue { get; }

    public YourEntityUpdatedEvent(long aggregateRootId, string fieldName, string oldValue, string newValue)
    {
        if (aggregateRootId <= 0)
            throw new ArgumentException("AggregateRootId は正の値である必要があります。");
        
        ArgumentNullException.ThrowIfNull(fieldName);

        AggregateRootId = aggregateRootId;
        FieldName = fieldName;
        OldValue = oldValue;
        NewValue = newValue;
        OccurredOn = DateTime.UtcNow;
    }
}
```

### 3. Entity でのイベント発行

```csharp
// src/Contexts/YourGroup/YourContext/YourContext.Domain/Entities/YourEntity.cs

using SupportAdvance.Common.Clocks;
using SupportAdvance.SharedKernel.Entities;
using SupportAdvance.Contexts.YourGroup.YourContext.Domain.DomainEvents;

namespace SupportAdvance.Contexts.YourGroup.YourContext.Domain.Entities;

public class YourEntity : Entity<long>
{
    private YourBusinessId _yourBusinessId = null!;
    private string _name = null!;

    public YourBusinessId YourBusinessId => _yourBusinessId;
    public string Name => _name;

    /// <summary>
    /// コンストラクタ（作成時にイベント発行）
    /// </summary>
    public YourEntity(long rowId, YourBusinessId yourBusinessId, string name, IClock clock)
    {
        ArgumentNullException.ThrowIfNull(yourBusinessId);
        ArgumentNullException.ThrowIfNull(name);

        Id = rowId;
        _yourBusinessId = yourBusinessId;
        _name = name;

        // ✓ イベント発行（rowId を使用）
        RaiseDomainEvent(new YourEntityCreatedEvent(rowId));
    }

    /// <summary>
    /// 名前更新メソッド（更新時にイベント発行）
    /// </summary>
    public void UpdateName(string newName)
    {
        ArgumentNullException.ThrowIfNull(newName);
        
        if (_name == newName)
            return;  // 変更がなければイベント発行しない

        var oldName = _name;
        _name = newName;

        // ✓ イベント発行（rowId を使用）
        RaiseDomainEvent(new YourEntityUpdatedEvent(
            this.Id,  // AggregateRootId
            nameof(Name),
            oldName,
            newName
        ));
    }
}
```

### 4. AggregateRoot でのイベント管理

```csharp
// src/Contexts/YourGroup/YourContext/YourContext.Domain/Entities/YourAggregate.cs

using SupportAdvance.Common.Clocks;
using SupportAdvance.SharedKernel.Entities;
using SupportAdvance.Contexts.YourGroup.YourContext.Domain.DomainEvents;

namespace SupportAdvance.Contexts.YourGroup.YourContext.Domain.Entities;

public class YourAggregate : AggregateRoot<long>
{
    private YourBusinessId _aggregateId = null!;
    private List<YourEntity> _children = new();

    public YourBusinessId AggregateId => _aggregateId;
    public IReadOnlyList<YourEntity> Children => _children.AsReadOnly();

    public YourAggregate(long rowId, YourBusinessId aggregateId, IClock clock)
    {
        ArgumentNullException.ThrowIfNull(aggregateId);

        Id = rowId;
        _aggregateId = aggregateId;

        // ✓ イベント発行（rowId を使用）
        RaiseDomainEvent(new YourAggregateCreatedEvent(rowId));
    }

    public void AddChild(YourEntity child)
    {
        ArgumentNullException.ThrowIfNull(child);
        
        if (_children.Any(c => c.Id == child.Id))
            throw new InvalidOperationException("同じ子要素は追加できません。");
        
        _children.Add(child);

        // ✓ Aggregate のイベント発行（Aggregate の rowId を使用）
        RaiseDomainEvent(new YourChildAddedEvent(
            this.Id,      // ← Aggregate の rowId
            child.Id      // ← 子の rowId
        ));
    }

    /// <summary>
    /// すべての子要素が発行したイベントを取得
    /// </summary>
    public IEnumerable<IDomainEvent> GetAllDomainEvents()
    {
        var events = DomainEvents.ToList();
        
        foreach (var child in _children)
        {
            events.AddRange(child.DomainEvents);
        }

        return events;
    }
}
```

### 5. イベント購読者（Event Handler）

```csharp
// src/Contexts/YourGroup/YourContext/YourContext.Application/EventHandlers/YourEntityCreatedEventHandler.cs

using SupportAdvance.SharedKernel.DomainEvents;
using SupportAdvance.Contexts.YourGroup.YourContext.Domain.DomainEvents;

namespace SupportAdvance.Contexts.YourGroup.YourContext.Application.EventHandlers;

public class YourEntityCreatedEventHandler : IDomainEventHandler<YourEntityCreatedEvent>
{
    private readonly ILogger<YourEntityCreatedEventHandler> _logger;

    public YourEntityCreatedEventHandler(ILogger<YourEntityCreatedEventHandler> logger)
    {
        _logger = logger ?? throw new ArgumentNullException(nameof(logger));
    }

    public async Task HandleAsync(YourEntityCreatedEvent @event)
    {
        ArgumentNullException.ThrowIfNull(@event);

        _logger.LogInformation(
            "YourEntity created: AggregateRootId={AggregateRootId}, OccurredOn={OccurredOn}",
            @event.AggregateRootId,
            @event.OccurredOn
        );

        // サイドエフェクト実行
        // - 他 BC への通知
        // - 外部システム連携
        // - キャッシュ無効化
        // など
        
        await Task.CompletedTask;
    }
}
```

### 6. イベントディスパッチャー

```csharp
// src/Infrastructure/DomainEventDispatcher.cs

using SupportAdvance.SharedKernel.DomainEvents;

namespace SupportAdvance.Infrastructure;

public class DomainEventDispatcher : IDomainEventDispatcher
{
    private readonly IServiceProvider _serviceProvider;
    private readonly ILogger<DomainEventDispatcher> _logger;

    public DomainEventDispatcher(IServiceProvider serviceProvider, ILogger<DomainEventDispatcher> logger)
    {
        _serviceProvider = serviceProvider ?? throw new ArgumentNullException(nameof(serviceProvider));
        _logger = logger ?? throw new ArgumentNullException(nameof(logger));
    }

    public async Task DispatchAsync(IEnumerable<IDomainEvent> events)
    {
        ArgumentNullException.ThrowIfNull(events);

        foreach (var @event in events)
        {
            await DispatchSingleEventAsync(@event);
        }
    }

    private async Task DispatchSingleEventAsync(IDomainEvent @event)
    {
        var handlerType = typeof(IDomainEventHandler<>).MakeGenericType(@event.GetType());
        var handlers = _serviceProvider.GetServices(handlerType);

        foreach (var handler in handlers)
        {
            try
            {
                var method = handlerType.GetMethod(nameof(IDomainEventHandler<IDomainEvent>.HandleAsync));
                if (method != null)
                {
                    await (Task)method.Invoke(handler, new object[] { @event })!;
                }
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Error handling domain event: {EventType}", @event.GetType().Name);
                throw;
            }
        }
    }
}
```

## ✅ 実装チェックリスト

### イベント定義

- [ ] **IDomainEvent を実装**: AggregateRootId, OccurredOn を持つ
- [ ] **AggregateRootId (rowId)**: イベント識別子として使用
- [ ] **検証**: コンストラクタで値を検証
- [ ] **不変**: 作成後は変更不可
- [ ] **過去形**: クラス名は "Created", "Updated" など

### Entity でのイベント発行

- [ ] **RaiseDomainEvent()**: Entity 内から呼び出し
- [ ] **rowId を渡す**: AggregateRootId にはイベント発行元の rowId
- [ ] **ビジネス変更時**: Update など重要な操作後に発行
- [ ] **コンストラクタ**: 作成時に Created イベントを発行

### イベント購読者

- [ ] **IDomainEventHandler を実装**: HandleAsync メソッド
- [ ] **DI に登録**: services.AddScoped<IDomainEventHandler<YourEvent>>(...)
- [ ] **非同期処理**: await で外部システムを呼び出し可能
- [ ] **例外処理**: イベント処理の失敗をハンドリング

## ❌ 避けるべきパターン

### パターン1: イベント ID として ビジネスID を使用

```csharp
// ✗ 禁止: ビジネス ID でイベント識別
public class YourEntityCreatedEvent : IDomainEvent
{
    public int YourBusinessId { get; }  // ✗ ビジネス ID
    
    public long AggregateRootId => throw new NotImplementedException();
}
```

**修正:**
```csharp
// ✓ rowId で識別
public class YourEntityCreatedEvent : IDomainEvent
{
    public long AggregateRootId { get; }  // ✓ rowId
}
```

### パターン2: イベント内でサイドエフェクトを実行

```csharp
// ✗ 禁止: イベント内でビジネスロジック
public class YourEntityCreatedEvent : IDomainEvent
{
    public YourEntityCreatedEvent(long aggregateRootId)
    {
        AggregateRootId = aggregateRootId;
        
        // ✗ イベント内でロジック実行
        SendEmailNotification();
        UpdateCache();
    }
}
```

**修正:**
```csharp
// ✓ イベントは発行のみ、ハンドラーでロジック実行
public class YourEntityCreatedEvent : IDomainEvent
{
    public long AggregateRootId { get; }
    public DateTime OccurredOn { get; }

    public YourEntityCreatedEvent(long aggregateRootId)
    {
        AggregateRootId = aggregateRootId;
        OccurredOn = DateTime.UtcNow;
    }
}

// Application 層のハンドラーで実行
public class YourEntityCreatedEventHandler : IDomainEventHandler<YourEntityCreatedEvent>
{
    public async Task HandleAsync(YourEntityCreatedEvent @event)
    {
        await SendEmailNotification(@event.AggregateRootId);
        UpdateCache(@event.AggregateRootId);
    }
}
```

### パターン3: Entity から直接イベント購読者を呼び出し

```csharp
// ✗ 禁止: Entity が イベント購読者に依存
public class YourEntity : Entity<long>
{
    private readonly IYourEventHandler _handler;

    public void UpdateName(string newName)
    {
        _name = newName;
        
        // ✗ Entity が直接ハンドラーを呼び出し
        await _handler.HandleUpdateAsync(newName);
    }
}
```

**修正:**
```csharp
// ✓ Entity がイベントを発行、Repository がハンドラーを呼び出し
public class YourEntity : Entity<long>
{
    public void UpdateName(string newName)
    {
        _name = newName;
        
        // ✓ イベント発行のみ
        RaiseDomainEvent(new YourEntityUpdatedEvent(this.Id, "Name", ..., newName));
    }
}

// Repository または UseCase が イベントをディスパッチ
public async Task UpdateEntityAsync(YourEntity entity)
{
    await _repository.UpdateAsync(entity);
    
    // イベントをディスパッチ
    await _eventDispatcher.DispatchAsync(entity.DomainEvents);
}
```

## 🔗 イベントフロー

```
1. Entity コンストラクタ
        ↓
2. RaiseDomainEvent(new YourEntityCreatedEvent(rowId))
        ↓
3. Repository.AddAsync(entity)
        ↓
4. DomainEventDispatcher.DispatchAsync(entity.DomainEvents)
        ↓
5. IDomainEventHandler<YourEntityCreatedEvent>.HandleAsync(@event)
        ↓
6. サイドエフェクト実行（メール送信、キャッシュ更新など）
```
