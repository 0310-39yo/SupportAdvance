# ドメインイベント 設計ガイド

Domain Driven Design におけるドメインイベントの設計と実装パターンです。

---

## 📋 基本原則

### ドメインイベントの役割

ドメインイベントは Entity が発行する「重要な業務上の変更」を表します。

- **疎結合**: イベント発行者と購読者が直接依存しない
- **非同期対応**: イベント購読者は非同期で処理可能
- **監査**: 何が起きたかを記録し、追跡可能にする
- **統合**: Bounded Context 間の連携メカニズム

### イベント識別子

ドメインイベントには **2つの識別子**があります：

| ID | 型 | 用途 | 例 |
|----|----|----|-----|
| **EventId** | DomainEventId（GUID） | このイベント自体を識別 | `DomainEventId.New()` |
| **AggregateRootId** | 集約固有のID（GUID ValueObject） | **どの集約が変更されたか**を特定 | `OrderId`, `EmployeeId` |

```csharp
using SupportAdvance.Common.Clocks;
using SupportAdvance.SharedKernel.ValueObjects.Identifiers;
using SupportAdvance.Contexts.YourGroup.YourContext.Domain.ValueObjects;

public interface IDomainEvent
{
    /// <summary>イベント一意識別子（トレーシング用）</summary>
    DomainEventId EventId { get; }
    
    /// <summary>集約ID（対象の集約を識別）※型パラメータで表現</summary>
    // TId AggregateRootId { get; }  ← 具体的なイベント定義で指定
    
    /// <summary>イベント発生時刻（JST）</summary>
    LocalDateTime OccurredAt { get; }
}
```

## 💡 実装パターン

### 1. イベント定義（集約固有の ID を指定）

```csharp
// src/Contexts/YourGroup/YourContext/YourContext.Domain/DomainEvents/YourEntityCreatedEvent.cs

using SupportAdvance.Common.Clocks;
using SupportAdvance.SharedKernel.Entities;
using SupportAdvance.SharedKernel.ValueObjects.Identifiers;
using SupportAdvance.Contexts.YourGroup.YourContext.Domain.ValueObjects;

namespace SupportAdvance.Contexts.YourGroup.YourContext.Domain.DomainEvents;

/// <summary>
/// YourEntity が作成されたことを表すドメインイベント
/// 
/// 【EventId】GUID で このイベント自体を識別
/// 【AggregateRootId】YourEntityId で どの Entity が作成されたかを特定
/// 【OccurredAt】イベント発生時刻（JST）
/// </summary>
public class YourEntityCreatedEvent : IDomainEvent
{
    /// <summary>イベント一意識別子（トレーシング用）</summary>
    public DomainEventId EventId { get; }
    
    /// <summary>作成された Entity の ID（集約固有の GUID ベース ValueObject）</summary>
    public YourEntityId AggregateRootId { get; }
    
    /// <summary>イベント発生時刻</summary>
    public LocalDateTime OccurredAt { get; }

    public YourEntityCreatedEvent(
        DomainEventId eventId,
        YourEntityId aggregateRootId,
        LocalDateTime occurredAt)
    {
        ArgumentNullException.ThrowIfNull(eventId);
        ArgumentNullException.ThrowIfNull(aggregateRootId);

        EventId = eventId;
        AggregateRootId = aggregateRootId;
        OccurredAt = occurredAt;
    }
}
```

### 2. 複数の属性を持つイベント

```csharp
// src/Contexts/YourGroup/YourContext/YourContext.Domain/DomainEvents/YourEntityUpdatedEvent.cs

using SupportAdvance.Common.Clocks;
using SupportAdvance.SharedKernel.Entities;
using SupportAdvance.SharedKernel.ValueObjects.Identifiers;
using SupportAdvance.Contexts.YourGroup.YourContext.Domain.ValueObjects;

namespace SupportAdvance.Contexts.YourGroup.YourContext.Domain.DomainEvents;

/// <summary>
/// YourEntity が更新されたことを表すドメインイベント
/// 【変更内容】FieldName, OldValue, NewValue をイベント属性として保持
/// </summary>
public class YourEntityUpdatedEvent : IDomainEvent
{

    public YourEntityId AggregateRootId { get; }  // 更新された Entity の ID
    public LocalDateTime OccurredAt { get; }
    
    // イベント固有の属性
    public string FieldName { get; }
    public string OldValue { get; }
    public string NewValue { get; }

    public YourEntityUpdatedEvent(
        DomainEventId eventId,
        YourEntityId aggregateRootId,
        string fieldName,
        string oldValue,
        string newValue,
        LocalDateTime occurredAt)
    {
        ArgumentNullException.ThrowIfNull(eventId);
        ArgumentNullException.ThrowIfNull(aggregateRootId);
        ArgumentNullException.ThrowIfNull(fieldName);

        EventId = eventId;
        AggregateRootId = aggregateRootId;
        FieldName = fieldName;
        OldValue = oldValue;
        NewValue = newValue;
        OccurredAt = occurredAt;
    }
}
```

### 3. Entity でのイベント発行

```csharp
// src/Contexts/YourGroup/YourContext/YourContext.Domain/Entities/YourEntity.cs

using SupportAdvance.Common.Clocks;
using SupportAdvance.SharedKernel.Entities;
using SupportAdvance.SharedKernel.ValueObjects.Identifiers;
using SupportAdvance.Contexts.YourGroup.YourContext.Domain.ValueObjects;
using SupportAdvance.Contexts.YourGroup.YourContext.Domain.DomainEvents;

namespace SupportAdvance.Contexts.YourGroup.YourContext.Domain.Entities;

public class YourEntity : Entity<YourEntityId>
{
    private RowId _entityRowId = null!;
    private string _name = null!;

    public string Name => _name;

    /// <summary>
    /// コンストラクタ（作成時にイベント発行）
    /// </summary>
    public YourEntity(YourEntityId id, string name, RowId? entityRowId = null, IClock? clock = null)
    {
        ArgumentNullException.ThrowIfNull(id);
        ArgumentNullException.ThrowIfNull(name);

        Id = id;  // 集約 ID（YourEntityId）
        _name = name;
        _entityRowId = entityRowId ?? RowId.New();

        // ✓ イベント発行
        // - EventId：イベント自体の ID（毎回新規生成）
        // - AggregateRootId：この Entity の ID（YourEntityId）
        if (clock != null)
        {
            RaiseDomainEvent(new YourEntityCreatedEvent(
                DomainEventId.New(),   // ← イベント自体のID
                this.Id,               // ← この Entity の ID（YourEntityId）
                clock.JstNow
            ));
        }
    }

    /// <summary>
    /// 名前更新メソッド（更新時にイベント発行）
    /// </summary>
    public void UpdateName(string newName, IClock clock)
    {
        ArgumentNullException.ThrowIfNull(newName);
        ArgumentNullException.ThrowIfNull(clock);
        
        if (_name == newName)
            return;  // 変更がなければイベント発行しない

        var oldName = _name;
        _name = newName;

        // ✓ イベント発行（EventId を新規生成）
        RaiseDomainEvent(new YourEntityUpdatedEvent(
            DomainEventId.New(),      // ← イベント自体のID（毎回新規）
            this.Id,                  // ← この Entity の ID（YourEntityId）
            nameof(Name),
            oldName,
            newName,
            clock.JstNow
        ));
    }
}
```

### 4. AggregateRoot でのイベント管理

```csharp
// src/Contexts/YourGroup/YourContext/YourContext.Domain/Entities/YourAggregate.cs

using SupportAdvance.Common.Clocks;
using SupportAdvance.SharedKernel.Entities;
using SupportAdvance.SharedKernel.ValueObjects.Identifiers;
using SupportAdvance.Contexts.YourGroup.YourContext.Domain.ValueObjects;
using SupportAdvance.Contexts.YourGroup.YourContext.Domain.DomainEvents;

namespace SupportAdvance.Contexts.YourGroup.YourContext.Domain.Entities;

public class YourAggregate : AggregateRoot<YourAggregateId>
{
    private RowId _aggregateRowId = null!;
    private List<YourEntity> _children = new();

    public IReadOnlyList<YourEntity> Children => _children.AsReadOnly();

    public YourAggregate(YourAggregateId id, RowId? aggregateRowId = null, IClock? clock = null)
    {
        ArgumentNullException.ThrowIfNull(id);

        Id = id;  // 集約 ID（YourAggregateId）
        _aggregateRowId = aggregateRowId ?? RowId.New();

        // ✓ イベント発行（EventId を新規生成）
        if (clock != null)
        {
            RaiseDomainEvent(new YourAggregateCreatedEvent(
                DomainEventId.New(),
                this.Id,  // ← AggregateRootId = YourAggregateId
                clock.JstNow
            ));
        }
    }

    public void AddChild(YourEntity child, IClock clock)
    {
        ArgumentNullException.ThrowIfNull(child);
        ArgumentNullException.ThrowIfNull(clock);
        
        if (_children.Any(c => c.Id == child.Id))
            throw new InvalidOperationException("同じ子要素は追加できません。");
        
        _children.Add(child);

        // ✓ Aggregate のイベント発行（EventId を新規生成）
        RaiseDomainEvent(new YourChildAddedEvent(
            DomainEventId.New(),  // ← イベント自体のID
            this.Id,              // ← この Aggregate の ID（YourAggregateId）
            child.Id,
            clock.JstNow
        ));
    }

    /// <summary>
    /// すべての子要素が発行したイベントを取得
    /// </summary>
    public IEnumerable<IDomainEvent> GetAllDomainEvents()
    {
        var events = DomainEvents.ToList();
        
        foreach (var child in _children)
        {
            events.AddRange(child.DomainEvents);
        }

        return events;
    }
}
```

### 5. イベント購読者（Event Handler）

```csharp
// src/Contexts/YourGroup/YourContext/YourContext.Application/EventHandlers/YourEntityCreatedEventHandler.cs

using Microsoft.Extensions.Logging;
using SupportAdvance.SharedKernel.Entities.DomainEvents;
using SupportAdvance.Contexts.YourGroup.YourContext.Domain.DomainEvents;

namespace SupportAdvance.Contexts.YourGroup.YourContext.Application.EventHandlers;

public class YourEntityCreatedEventHandler : IDomainEventHandler<YourEntityCreatedEvent>
{
    private readonly ILogger<YourEntityCreatedEventHandler> _logger;

    public YourEntityCreatedEventHandler(ILogger<YourEntityCreatedEventHandler> logger)
    {
        _logger = logger ?? throw new ArgumentNullException(nameof(logger));
    }

    public async Task HandleAsync(YourEntityCreatedEvent @event)
    {
        ArgumentNullException.ThrowIfNull(@event);

        // イベント情報から対象 Entity を特定
        var entityId = @event.AggregateRootId;

        _logger.LogInformation(
            "YourEntity created: EntityId={EntityId}, EventId={EventId}, OccurredAt={OccurredAt}",
            entityId,
            @event.EventId,
            @event.OccurredAt
        );

        // サイドエフェクト実行
        // - 他 BC への通知
        // - 外部システム連携
        // - キャッシュ無効化
        // など
        
        await Task.CompletedTask;
    }
}
```

### 6. イベントディスパッチャー

```csharp
// src/Infrastructure/DomainEventDispatcher.cs

using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Logging;
using SupportAdvance.SharedKernel.Entities.DomainEvents;

namespace SupportAdvance.Infrastructure;

public class DomainEventDispatcher : IDomainEventDispatcher
{
    private readonly IServiceProvider _serviceProvider;
    private readonly ILogger<DomainEventDispatcher> _logger;

    public DomainEventDispatcher(IServiceProvider serviceProvider, ILogger<DomainEventDispatcher> logger)
    {
        _serviceProvider = serviceProvider ?? throw new ArgumentNullException(nameof(serviceProvider));
        _logger = logger ?? throw new ArgumentNullException(nameof(logger));
    }

    public async Task DispatchAsync(IEnumerable<IDomainEvent> events)
    {
        ArgumentNullException.ThrowIfNull(events);

        foreach (var @event in events)
        {
            await DispatchSingleEventAsync(@event);
        }
    }

    private async Task DispatchSingleEventAsync(IDomainEvent @event)
    {
        var handlerType = typeof(IDomainEventHandler<>).MakeGenericType(@event.GetType());
        var handlers = _serviceProvider.GetServices(handlerType);

        foreach (var handler in handlers)
        {
            try
            {
                var method = handlerType.GetMethod(nameof(IDomainEventHandler<IDomainEvent>.HandleAsync));
                if (method != null)
                {
                    await (Task)method.Invoke(handler, new object[] { @event })!;
                }
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Error handling domain event: {EventType}", @event.GetType().Name);
                throw;
            }
        }
    }
}
```

## ✅ 実装チェックリスト

### イベント定義

- [ ] **IDomainEvent を実装**: EventId, AggregateRootId（集約固有のID）, OccurredAt を持つ
- [ ] **EventId**: DomainEventId（GUID）で各イベントを一意識別
- [ ] **AggregateRootId**: 集約固有の ID ValueObject（OrderId, EmployeeId など）
- [ ] **検証**: コンストラクタで値を検証（null チェック）
- [ ] **不変**: 作成後は変更不可
- [ ] **過去形**: クラス名は "Created", "Updated" など

### Entity でのイベント発行

- [ ] **RaiseDomainEvent()**: Entity 内から呼び出し
- [ ] **EventId を新規生成**: `DomainEventId.New()` で毎回新規ID
- [ ] **AggregateRootId に this.Id を渡す**: 集約固有のID（YourEntityId など）
- [ ] **ビジネス変更時**: Update など重要な操作後に発行
- [ ] **コンストラクタ**: 作成時に Created イベントを発行

### イベント購読者

- [ ] **IDomainEventHandler<TEvent> を実装**: HandleAsync メソッド
- [ ] **AggregateRootId から対象を特定**: イベント処理で集約 ID を使用
- [ ] **DI に登録**: services.AddScoped<IDomainEventHandler<YourEvent>>(...)
- [ ] **非同期処理**: await で外部システムを呼び出し可能
- [ ] **例外処理**: イベント処理の失敗をハンドリング

## ❌ 避けるべきパターン

### パターン1：AggregateRootId に long（RowId）を使用

```csharp
// ✗ 禁止：型不安全、異なる集約のIDが混在可能
public class YourEntityCreatedEvent : IDomainEvent
{
    public long AggregateRootId { get; }  // ✗ long型、型チェックなし
    
    public DomainEventId EventId { get; }
    public LocalDateTime OccurredAt { get; }
}

// ✓ 正しい：集約固有の ID 型を使用
public class YourEntityCreatedEvent : IDomainEvent
{
    public YourEntityId AggregateRootId { get; }  // ✓ 型安全
    
    public DomainEventId EventId { get; }
    public LocalDateTime OccurredAt { get; }
}
```

### パターン2：イベント内でサイドエフェクトを実行

```csharp
// ✗ 禁止：イベント内でビジネスロジック
public class YourEntityCreatedEvent : IDomainEvent
{
    public YourEntityCreatedEvent(DomainEventId eventId, YourEntityId aggregateRootId)
    {
        EventId = eventId;
        AggregateRootId = aggregateRootId;
        
        // ✗ イベント内でロジック実行
        SendEmailNotification();
        UpdateCache();
    }
}

// ✓ イベントは発行のみ、ハンドラーでロジック実行
public class YourEntityCreatedEvent : IDomainEvent
{
    public DomainEventId EventId { get; }
    public YourEntityId AggregateRootId { get; }
    public LocalDateTime OccurredAt { get; }

    public YourEntityCreatedEvent(DomainEventId eventId, YourEntityId aggregateRootId, LocalDateTime occurredAt)
    {
        EventId = eventId;
        AggregateRootId = aggregateRootId;
        OccurredAt = occurredAt;
    }
}

// Application 層のハンドラーで実行
public class YourEntityCreatedEventHandler : IDomainEventHandler<YourEntityCreatedEvent>
{
    public async Task HandleAsync(YourEntityCreatedEvent @event)
    {
        await SendEmailNotification(@event.AggregateRootId);
        UpdateCache(@event.AggregateRootId);
    }
}
```

### パターン3：Entity から直接イベント購読者を呼び出し

```csharp
// ✗ 禁止：Entity が イベント購読者に依存
public class YourEntity : Entity<YourEntityId>
{
    private readonly IYourEventHandler _handler;

    public void UpdateName(string newName)
    {
        _name = newName;
        
        // ✗ Entity が直接ハンドラーを呼び出し
        _handler.HandleUpdateAsync(newName);  // ← 密結合
    }
}

// ✓ Entity がイベントを発行、Repository がハンドラーを呼び出し
public class YourEntity : Entity<YourEntityId>
{
    public void UpdateName(string newName, IClock clock)
    {
        _name = newName;
        
        // ✓ イベント発行のみ（疎結合）
        RaiseDomainEvent(new YourEntityUpdatedEvent(
            DomainEventId.New(),
            this.Id,
            nameof(Name),
            oldValue,
            newName,
            clock.JstNow
        ));
    }
}

// Repository または UseCase が イベントをディスパッチ
public async Task UpdateEntityAsync(YourEntity entity)
{
    await _repository.UpdateAsync(entity);
    
    // イベントをディスパッチ
    await _eventDispatcher.DispatchAsync(entity.DomainEvents);
}
```

## 🔗 イベントフロー

```
1. Entity.UpdateName() メソッド実行
        ↓
2. RaiseDomainEvent(new YourEntityUpdatedEvent(...))
        ↓
3. Repository.UpdateAsync(entity)
        ↓
4. EventDispatcher.DispatchAsync(entity.DomainEvents)
        ↓
5. IDomainEventHandler<YourEntityUpdatedEvent>.HandleAsync(@event)
   （@event.AggregateRootId から対象 Entity を特定）
        ↓
6. サイドエフェクト実行（メール送信、キャッシュ更新など）
```
