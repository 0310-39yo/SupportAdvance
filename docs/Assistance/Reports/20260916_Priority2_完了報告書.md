## 🔍 テスト内容の詳細

### UserAuthSessionMapperTests

**責務:** UserAuthSession Entity ↔ UserAuthSessionDbModel の双方向マッピング検証

#### VO_MAP グループ（Entity ↔ DbModel マッピング）

| テスト | 検証内容 |
|-------|---------|
| VO_MAP_01 | Entity を DbModel に変換時、すべてのビジネスフィールドが正確にマップされることを検証 |
| VO_MAP_02 | LoggedOutAt を持つ Entity を変換時、ログアウト日時が正しく設定されることを検証 |
| VO_MAP_03 | DbModel から Entity に復元時、すべてのフィールドが正確に復元されることを検証 |

#### VO_TYPE グループ（型変換検証）

| テスト | 検証内容 |
|-------|---------|
| VO_TYPE_01 | DateTime（DB型） ↔ LocalDateTime（Domain型）の往復変換が一貫性を保つことを検証 |

**技術的特徴:**
- Mapper は純粋な型変換のみに専念（Clock 依存なし）
- 監査フィールド（CreatedAt/UpdatedAt/DeletedAt）設定は Repository の責務
- LocalDateTime による型安全性確保

### PasswordHashServiceTests

**責務:** PBKDF2-SHA256 ハッシュ生成・検証処理のセキュリティ検証

#### VO_HASH グループ（ハッシュ生成・検証）

| テスト | 検証内容 |
|-------|---------|
| VO_HASH_01 | 有効なパスワードでハッシュ文字列が生成されることを検証 |
| VO_HASH_02 | 同じパスワードでも Salt 差により異なるハッシュが生成されることを検証（セキュリティ確認） |
| VO_HASH_03 | 同じ Salt で同じハッシュが生成される決定性を検証 |
| VO_HASH_04 | 正しいパスワード入力時に VerifyPassword が true を返すことを検証 |
| VO_HASH_05 | 間違ったパスワード入力時に VerifyPassword が false を返すことを検証 |

#### VO_SECURITY グループ（セキュリティ異常系）

| テスト | 検証内容 |
|-------|---------|
| VO_SECURITY_01 | 空パスワード入力時に ArgumentException が発生することを検証 |
| VO_SECURITY_02 | null ハッシュ入力時に VerifyPassword が false を返すことを検証 |
| VO_SECURITY_03 | 破損ハッシュ入力時に VerifyPassword が false を返すことを検証 |

**技術的特徴:**
- PBKDF2-SHA256 によるセキュアなパスワードハッシュ化
- Salt ベース方式で同じパスワードでも毎回異なるハッシュ生成
- タイミング攻撃耐性のある定数時間比較実装
