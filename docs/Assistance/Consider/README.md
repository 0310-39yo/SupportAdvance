### 1. **参照しないこと**
- 実装時にこのディレクトリ内のドキュメントを参照しないでください
- アーキテクチャやガイドラインの**公式情報源ではありません**

- これらのドキュメントは検討段階のため、不完全または暫定的な内容を含みます
- 設計方針が定まっていない場合があります

### 3. **修正対象外**
- ドキュメント齟齬調査や品質改善時に、このディレクトリ内のドキュメントは対象外とします
- 実装との矛盾が存在する可能性があります
